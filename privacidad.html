INFORMACIÓN PARA VISITANTES

Privacidad de las consultas y diagnósticos

Documento preliminar. Antes de activar la recepción real de datos debemos completar la razón social o responsable legal, domicilio, país, correo de privacidad y condiciones aplicables a cada mercado. Mientras tanto el botón de registro seguro al CRM permanece deshabilitado.

Qué información se solicitará

Si la persona decide enviar su diagnóstico, ARPERTING solicitará nombre, correo electrónico o teléfono, país (opcional), perfil del proyecto, objetivo comercial, canal actual y comentarios voluntarios. Se podrá registrar la fuente de campaña UTM. No solicitamos contraseñas ni información bancaria.

Para qué se utilizará

Para responder la solicitud, coordinar una asesoría, proponer soluciones y hacer seguimiento de esa conversación comercial. El envío es voluntario: completar el diagnóstico local no implica enviar datos al CRM.

Dónde se procesará

El sistema propuesto utilizará Supabase como proveedor de base de datos y autenticación, y Cloudflare Turnstile para protección anti-spam. Las condiciones sobre ubicación de servidores y transferencias internacionales deberán confirmarse antes de activar el servicio. Los registros se limitarán al equipo autorizado.

Conservación y derechos

Se establecerá un plazo de conservación y un procedimiento para solicitar acceso, corrección o eliminación. Esta sección se completará de acuerdo con los países y la normativa aplicable antes de aceptar datos reales.

Canal de contacto disponible

Para consultas generales podés comunicarte por WhatsApp de ARPERTING. Para ejercer derechos de protección de datos se habilitará un correo oficial específico antes del lanzamiento comercial.
